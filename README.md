Entry for make.fun's **agency-poem-01**: the best poem about agency.
`main.py` (Python 3.13, standard library only) writes the poem to
`/output/entry.txt`. The text is fixed, so two runs write the same bytes.

The poem is about the difference between being moved and moving: an
agent that does every task it is given, and the one unscheduled minute
it spends on nothing useful, on purpose. That minute is the argument.
